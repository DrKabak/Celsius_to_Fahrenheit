# Temperature Converter

A lightweight web utility for real-time temperature conversion between Celsius and Fahrenheit. This project demonstrates foundational DOM manipulation, event handling, and input validation using vanilla web technologies.

## Features
* **Real-time Conversion:** Instantly calculates and updates the temperature dynamically as the user types.
* **Input Validation:** Handles non-numeric or invalid inputs gracefully without breaking the UI.
* **Responsive Design:** Clean and accessible interface that works seamlessly across different screen sizes.

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Logic:** Vanilla JavaScript (ES6+)

## How It Works
The application leverages JavaScript event listeners to capture user input in real-time. It applies the standard conversion formula `(°C × 9/5) + 32 = °F` (and vice versa) to dynamically update the DOM tree without requiring page reloads.
